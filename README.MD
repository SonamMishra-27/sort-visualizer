# Sorting algorithm visualizer

This is a web application built using HTML, CSS, Javascript to visualize classic sorting algorithms such as bubble, insertion, selection, merge, quick 

**Live-** [sorting visualizer](https://github.com/SonamMishra-27/sort-visualizer) 

**Code-** [sort visualizer code](https://github.com/SonamMishra-27/sort-visualizer)

## Purpose

I made this sorting visualizer web application to improve my skills more in
HTML, CSS, and JS. And to help the beginners in programming to gain more knowledge and understanding on sorting algorigthms by visualizing them.

##  Features
- Visual representation of sorting steps
- Adjustable speed and size of dataset
- Understand algorithm time complexity intuitively

##  What I learned
- DOM manipulation in JavaScript
- How different sorting algorithms behave
- Time and space complexity insights

## What the Sorting algorithms inside this application

This application supports the following sorting algorithms:

1. **Bubble Sort**.
2. **Insertion Sort**.
3. **Selection Sort**.
4. **Merge Sort**.
5. **Quick Sort**.
